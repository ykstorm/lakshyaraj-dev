## What it does

Homesty is a buyer-side real-estate chat. Buyers chat directly with a listing — asking about specs, location, and price — and the app answers from the property data. Agents get qualified leads out the other end. The chat handles the repetitive property-spec questions so the human agent only spends time on buyers who are actually serious.

## Why this approach

The easy version replaces the agent. This one keeps the human in the loop on purpose. The chat's job is to filter tire-kickers and field the same five questions every listing gets, not to close the deal. That's the trade-off: it's deliberately not autonomous, because the agent relationship is the product.

## How it's built

Next.js and React on the front, Node for the API, and Postgres with Prisma for the listings and app data. Buyer questions are answered against the property data, and qualified conversations get routed to the listing's agent as a lead. It's deployed on Vercel, with Sentry behind it for error tracking. So far the pieces are the landing page, the chat screen, a REST API, admin pages, login, and an audit log.

## Known limitations

- Coverage is a limited set of listings; other cities aren't in the index yet.
- RERA lookup is best-effort against a scraped index, not the live regulator API, so it can lag.
- It depends on listing data quality; a thin or stale listing gives the chat little to answer from.
