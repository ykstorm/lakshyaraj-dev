# lakshyaraj-dev

My personal site and portfolio — **[lakshyaraj-dev.vercel.app](https://lakshyaraj-dev.vercel.app)**.

A small Next.js site: a short intro, a list of the projects I've built, a
"now" note, a few writing posts, and links to my resume, GitHub and npm.

## Stack

Next.js (App Router), React, TypeScript, Tailwind CSS, next-themes, MDX for the
writing, deployed on Vercel.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint     # eslint
```

## Structure

```
app/            routes, metadata, sitemap/robots/OG image
components/      UI components
data/           projects and "now" content
content/        MDX for projects and blog posts
```
